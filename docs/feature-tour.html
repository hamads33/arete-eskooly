Feature Tour

Every feature built in this release, with a direct link and the account to use. Links open on your local server: http://127.0.0.1:8090.

Start the app first: php -S 127.0.0.1:8090 -t public public/router.php from the project folder. Local demo data comes from php database/seed_showcase.php --seed. Local only; never run it on the live server.
